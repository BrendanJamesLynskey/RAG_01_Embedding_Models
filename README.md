# RAG 01 — Embedding Models

A deep-dive into the embedding layer of RAG pipelines: dense versus sparse representations, bi-encoder versus cross-encoder architectures, ColBERT late-interaction scoring, Matryoshka representation learning, modern model families (BGE, GTE, E5, Voyage, OpenAI text-embedding-3, Cohere, Nomic, Jina), domain-adaptation techniques (TSDAE, GPL, hard-negative mining), and how to evaluate with MTEB and BEIR.
